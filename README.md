# Сервис аутентификации с защитой от ботов

Практическое задание №2: регистрация, вход и личный кабинет с математической капчей.

## Стек

| Слой | Технология |
|---|---|
| Backend | Node.js 22+ / Express |
| База данных | SQLite (встроенный модуль `node:sqlite`, без нативных зависимостей) |
| Сессии | `express-session` + собственное SQLite-хранилище (без JWT) |
| Хеширование пароля | `crypto.pbkdf2` (sha512, 210 000 итераций) |
| Frontend | Чистый HTML + CSS + JavaScript, без фреймворков |
| Оформление | Тёмная тема, строгий минимализм, адаптив ≤ 480px |

## Быстрый старт

Из корня проекта:

```bash
npm run setup
npm run dev
```

`npm run setup` ставит зависимости в `server/`, `npm run dev` запускает сервер с автоперезапуском.
Обе команды — обёртки над `server/`, так что то же самое можно делать и напрямую:

```bash
cd server && npm install && npm run dev
```

Файл `server/.env` создаётся копией `server/.env.example` (в репозитории он не хранится):

```bash
cp server/.env.example server/.env
```

Открыть http://localhost:3000 — произойдёт редирект на `/login`.

База создаётся автоматически при первом запуске в `server/data/app.db`.


## Страницы

| Маршрут | Описание |
|---|---|
| `/register` | Регистрация. Логин (латиница+цифры, 3–20), email, пароль (≥6, буквы+цифры), подтверждение, капча |
| `/login` | Вход по логину **или** email + капча |
| `/profile` | Приветствие, email, дата регистрации, роль, кнопка «Выйти». Неавторизованных редиректит на `/login` |

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/captcha` | Новая математическая задача; ответ хранится только в сессии |
| `POST` | `/api/register` | Регистрация. Ошибки — по полям, вместе с новой капчей |
| `POST` | `/api/login` | Вход. При неудаче — общее «Неверный логин или пароль» |
| `GET` | `/api/me` | Данные текущего пользователя, иначе 401 |
| `POST` | `/api/logout` | Разрушает сессию |

Формат ошибки:

```json
{ "errors": { "captcha": "Неверный ответ капчи" },
  "captcha": { "question": "Сколько будет 7 + 4?" } }
```
